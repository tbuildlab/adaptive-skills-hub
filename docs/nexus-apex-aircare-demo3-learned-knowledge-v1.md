## 1. Interpretation and use

Apex FACT means source-reported history; these principles are supported INFERENCE unless explicitly a recorded source observation. PROPOSAL remains unaccepted. UNKNOWN, DEFERRED, NOT REPRODUCED / ROOT CAUSE UNKNOWN, UNAVAILABLE and partial execution retain their exact limitations. No current live, tool or provider validation is claimed.

Every lesson below names source evidence, general principle, scope, limitation, existing accepted relation and promotion candidacy. Candidate recommendations are advisory. Reuse existing CP/ES and A-F meanings; do not import NEXUS-AAC as a second rule catalog. ## 3. Genuine deltas versus useful examples

Only D01 and D02 in [synthesis §6](nexus-demo2-demo3-cross-project-synthesis-v1.md) warrant controlled promotion review. D01 concerns when a scoped input-test decision is made, not a new Gate D or test technology. D02 concerns distinct, evidence-bound diagnostic observations, not a linear lifecycle or replacing security analyzer dispositions.

Intermediate responsive widths, meaningful affordances, measured text floors, native controls, warning descriptions and role-bound application/documentation SHAs are refinements/examples within existing applicable checks. They remain learned knowledge; no additional top-level gate or deployment fact is justified. The absence of repeated Apex-style false positives or a documented early-harness gap in Northstar limits confidence for those deltas.
