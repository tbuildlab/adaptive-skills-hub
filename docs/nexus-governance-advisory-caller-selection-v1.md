## 4. Bounded design refinement and selection

Initial **B: EXISTING CALLER IDENTIFIED — DESIGN REFINEMENT REQUIRED BEFORE INTEGRATION**: the handoff is safe, but source selection must be explicit rather than inferred from task text/file format or generated from plan facts.

Refinement: optional `plan --handoff --governance-advisory-context <canonical-project-relative-path>`. The path must identify exactly one existing `explicit_task_file` / `project_evidence` context item already captured because the task named it. Reject absolute/traversal/noncanonical selections; do not read/fetch/resolve the selector as a file. Missing/skipped/ambiguous/changed-byte context yields a bounded PRESERVE_UNKNOWN advisory with null report. Restrict the option to the existing stateless handoff; reject other plan modes before catalog/context acquisition. Omitting it performs no evaluation and preserves original output.

Use the unchanged `review_bytes` directly, because the selected input contains a source assessment, not an independently supplied historical derived report. Creating a report and comparing it with itself through `review_pair` would provide no traceability evidence. Existing pairing helper remains available for its separately scoped offline purpose and unchanged.

The attached advisory has fixed zero authority, no dispatch, source evidence/coverage UNVERIFIED, freshness UNKNOWN and subject scope UNVERIFIED. Record captured context position/digest, fixed consumer identity and the unchanged report. Do not echo supplied text/path, turn this into a task verdict or attest loaded evaluator bytes. A structurally coherent all-PASS source still needs independent review. Missing/malformed/version/dependency/evaluator failure cannot grant anything. Evaluator exception text must never be printed. Source/output remain derived versus original.

Re-evaluation: **A. EXISTING READ-ONLY ADVISORY CALLER IDENTIFIED — BOUNDED INTEGRATION JUSTIFIED.** Existing explicit-file acquisition and a pure display caller suffice for optional structural advice only. They do not suffice for mandatory evidence adjudication; that remains prohibited. No new trust boundary, caller, privileged component, service or runtime is introduced.
