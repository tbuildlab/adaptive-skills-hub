## Explicit unsupported paths

**External/remote publication recovery is UNSUPPORTED. Remote publication outcome/
reconciliation is NOT QUALIFIED.** No Nexus automatic publisher, remote adapter,
remote side-effect retry or remote recovery path is admitted. Ordinary separately
authorized Git checkpoint/tag publication and exact readback do not qualify a
Nexus remote-recovery product feature. Unknown publication stops; it does not
authorize a blind retry or release unresolved exposure.

G5 delegation/concurrency is disabled. No generic remote MCP, arbitrary deferred
tools, untrusted scripts/hooks, generic Agents, new model/backend, conversation
compactor, cloud service, autonomous installer or replacement executor is added.
Strict native restrictions refer only to the exact fixed command/loader/Job/MXC
composition, not every operation of the desktop Host. Core trusted-local hooks
inherit no native MXC confinement guarantee. Helper process containment is not
general semantic Agent attenuation. General compaction and arbitrary transitive
tool discovery remain outside the fixed admitted recipes; summaries cannot
replace exact policy/input/authority/source bindings.

Native CPU termination is periodic and may overshoot its threshold. Wall timeout
requests termination followed by bounded cleanup; it is not rollback of effects.
Partial/late/unknown output remains quarantined and cannot automatically retry.
No general machine-level privacy certification or confidential user input
processing is claimed. PUBLIC local-only routing evidence is labeled as such.

N01/PREAUTH/public-pin/DynamoDB/custody/distributed recovery remain optional
high-assurance research HOLD. No related account, resource, grant or old lifecycle
state is revived. Production adapters remain DENY; **REAL_ADMISSION=NO**.

## Distribution and release identity

The proposed release is the existing reproducible **private source package and
exact repository/tag evidence**, with this profile and the accepted amendment
as reviewable release-side records. It does not upgrade the installed Desktop
plugin, build a new embedded runtime, redistribute llama.cpp/GGUF/native Host
binaries, install dependencies, activate quarantined candidates or deploy a
service. Existing distribution/install/update/revocation tests are included in
the final full regression; three unavailable embedded-runtime environments and
one Windows symlink privilege skip remain explicit if unchanged.

Historical source documents keep their dated statuses and limitations. This
profile governs current release claims; those historical backend/preparation
labels are not current milestone reopenings. Reproducibility/data-exclusion and
source/dependency provenance must be checked against the actual release artifact.
This profile and all final review/test/artifact identities must be included in
the final Owner review package. No final tag precedes exact Owner acceptance.
