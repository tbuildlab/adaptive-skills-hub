## Evidence method and limits

The search covered current Nexus docs/research, the four identified project
repositories' first-party reports, design/phase documents, application source,
package metadata and their available Git histories. Targeted case-insensitive
history/content searches checked the owner-named candidates, then followed
references actually recorded in project research. Copied catalog links alone
are not treated as consultation of every linked brand/site. No unrelated browser
history, account/session records, secrets or external page content was ingested.
No reference site, CLI, provider or website regression was newly executed.

Current source reports are the evidence for historical consultation. Original
tool outputs are identified where retained; a report of use with no exact output
retains that limitation. CONFIRMED_USED includes specifically documented guidance
or conceptual influence, not just runtime packages. Per-project/phase observations
remain separate: a strong Noma/Apex record cannot qualify Northstar's missing
advisor transcript. Aggregate status selects confirmed influence when supported;
otherwise explicit rejection, consultation, consideration or bounded absence.
REJECTED means adoption declined for the specific brief, not that the resource is
bad or universally forbidden. SUPERSEDED observations preserve changed decisions.

NOT_FOUND is absence of a project-linked match in this search scope. Its usage is
still UNKNOWN / INSUFFICIENT_EVIDENCE; it does not prove historical non-use.
Arlan, Amieiro and Libraries.dev have no resolved source identity/URL here.
The index contains operation-level INSUFFICIENT_EVIDENCE and SUPERSEDED observations
even though no aggregate source row needs those statuses. Counts are source rows,
not project observations or occurrences of names.

Photo asset/photographer ledgers, general framework/font documentation and locally
supplied reference images remain in their existing project evidence; they are not
counted as additional external website/design-tool consultations. This is a
complete bounded audit, not an assertion that all historical browsing is known.
