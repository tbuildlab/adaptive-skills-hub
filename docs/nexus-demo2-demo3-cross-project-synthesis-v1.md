## 7. Finding and reproduction analysis against existing Nexus

Inspected actual `ash/ecosystem_evidence.py` `_finding` / `_build_static_report`: static findings already bind subject/evidence/configuration/analyzer, category, severity, disposition, reasons and zero authority. `ash/ecosystem_bridge.py` and the [Slice 3C contract](nexus-post-r5-runtime-integration-slice3c-adr-pds.md) preserve validation/quarantine boundaries. `ash/evaluation.py` and [Slice 3B](nexus-post-r5-runtime-integration-slice3b.md) bind declared checks and subject digests, with existing closed outcomes and separate execution/review/validation states.

Thus Nexus already has findings and evidence-scoped decisions. A universal finding-state engine is redundant/unjustified. The inspected records do not supply a general UI diagnostic reproduction/root-cause/fix chain; D02 is only a documentary refinement for existing triage records. It cannot redefine or waive deterministic mandatory analyzer findings. No existing schema is changed.

FINDING is an observation with source and criterion, not necessarily CONFIRMED_DEFECT. REPRODUCED names a demonstrated behavior under declared conditions, not by itself a defect or causal explanation. CONFIRMED_DEFECT requires contradiction of an applicable criterion. FALSE_POSITIVE requires positive scoped evidence that the detector's purported problem/criterion does not apply to the observed subject, not simply a failed reproduction. NOT_REPRODUCED leaves the issue unresolved within the attempted scope. ROOT_CAUSE_UNKNOWN can coexist with reproduction. FIXED requires authorized change linked to the issue; a resolved claim additionally needs relevant revalidation evidence. VALIDATED names checks/subject/time, not universal safety. These explanatory terms are PROPOSED analysis, not accepted lifecycle values or a required progression.

Source examples: 768 px overflow was reproduced, contradicted the project's no-overflow criterion, and had a recorded fix/later measured checks. Side-tab false positives have source-reported rendered-context justification; not independently re-executed here. Hydration remains NOT REPRODUCED / ROOT CAUSE UNKNOWN, neither failed validation nor fixed. Mandatory unknowns retain STOP; an optional scoped diagnostic can remain pending with explicit impact, never be relabeled PASS.
