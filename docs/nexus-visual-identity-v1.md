# Nexus Visual Identity Baseline

## Accepted avatar

The user-approved ringed multi-flow gate image is the official Nexus avatar
baseline. Preserve its existing off-white, charcoal, taupe, and metallic-neutral
palette and its multi-flow → gate → single-output composition. Do not add text,
letters, or new visual motifs, and do not reinterpret it as an AI glow,
cyberpunk, planet, or orbit mark.

## Canonical files

- `assets/brand/nexus/nexus-avatar-master.png` is an unchanged byte-for-byte
  copy of the supplied 1254 × 1254 PNG. Keep it as the archival master.
- `assets/brand/nexus/nexus-avatar-500.png` is the 500 × 500 square profile
  asset. It scales the original artwork uniformly to 460 × 460 and centers it
  on a sampled off-white background, leaving 4% canvas padding on each side.
  No content is redrawn or cropped.

The supplied master is 2,048,098 bytes. The profile asset is 267,327 bytes,
under GitHub's documented 1 MB limit; GitHub recommends a profile picture of
about 500 × 500 pixels. See the
[GitHub profile image requirements](https://docs.github.com/en/account-and-profile/reference/profile-reference).

Use the profile asset for square or circular avatar slots and README/project
identity. Its circular safe area retains the outer ring with added breathing
room. At 32–64 px the gate and output direction remain recognizable; at 24 px
fine metallic detail merges, as expected for a photographic illustration.

## Platform use

Use this same visual as the source for GitHub, the ChatGPT Nexus plugin, and
Nexus project showcases. The supplied square profile asset is ready for upload
to common avatar slots. Confirm any platform-specific upload constraints in the
target interface at time of use; this guide does not claim a verified
ChatGPT-plugin-specific image specification or apply the image to external
accounts.

For wide project previews, place the avatar within the existing composition
without altering the avatar artwork. Keep this approved image as the single
visual source of truth.
