## 1. Result, baseline, and fixed decision rule

Baseline: `nexus-v2-g2-development`, HEAD `5109207ad23086a18ad9417ac8e34f85b527c7c1`, clean before this draft; source MANIFEST 176/176 matched. This matrix applies the accepted [Route B P1–P12 contract](nexus-g2-route-b-provider-neutral-host-contract-v1.md), accepted [provider fact matrix](nexus-g2-route-b-provider-documentation-fact-matrix-v1.md), [adversarial review](nexus-g2-route-b-provider-interface-adversarial-review-v1.md) and [acceptance](nexus-g2-route-b-provider-interface-acceptance-v1.md), together with the accepted [Responsibility Re-baseline](nexus-g2-responsibility-rebaseline-review-v1.md) and [acceptance](nexus-g2-responsibility-rebaseline-acceptance-v1.md). It does not reopen their conclusions or add provider facts.

**Overall conclusion B: NO PROVIDER EXPERIMENT IS JUSTIFIED UNTIL SPECIFIC AUTHORITATIVE EVIDENCE IS OBTAINED.** All three providers have conditional composite evidence paths, but the provider-controlled half of mandatory pre-experiment properties is not yet identified sufficiently. Daytona's documented organization-wide toolbox authority makes P2 a particularly strong blocker, but the accepted P2 contract permits an equivalent actor-exclusion composition and the repository does not prove that path impossible. It is therefore C, not D.

The classifications are:

- **A — EXPERIMENT-RESOLVABLE:** supported interface semantics already exist; a bounded externally observed fault/negative test can establish the remaining exact-configuration behavior.
- **B — AUTHORITATIVE-CONTRACT-REQUIRED:** experiment cannot establish guarantee, complete pricing/cutoff semantics, or future identity/drift behavior controlled by the provider.
- **C — COMPOSITE:** authoritative semantics define what is guaranteed/observable, and bounded testing binds actual behavior to the exact configuration.
- **D — CURRENTLY UNRESOLVABLE:** no identified path preserves the property without a new architecture/trust boundary or weakening.

Resource vector `K/$/N/A/S` means experiment needs credential, potentially paid resource, network, provider account, and persistent evidence/state respectively. `Y/Y/Y/Y/Y-local` uses one ephemeral hosted unit and mandatory owner-protected local evidence, with no persistent provider workload resource. `S=provider` is used only when provider-retained records/artifacts are also required. `—` means no experiment can resolve that row. An A result is scoped measured evidence, not a universal provider guarantee. A C row resolves only after **both** halves pass; the experiment alone removes one blocker. A B row cannot be resolved by execution.
